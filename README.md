# Pul hisobi — личный учёт прихода и расхода (PWA для iPhone)

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | само приложение (весь код внутри) |
| `manifest.webmanifest` | название и иконка для экрана «Домой» |
| `sw.js` | работа без интернета |
| `icon-180.png`, `icon-192.png`, `icon-512.png` | иконки |
| `serve.js` | только для проверки на компьютере, на хостинг не нужен |

## Как поставить на iPhone (один раз, ~10 минут)

iPhone добавляет приложение на экран «Домой» только с адреса **https://**. Бесплатный вариант — GitHub Pages.

1. Зарегистрируйся на https://github.com (если ещё нет аккаунта).
2. Справа вверху **+** → **New repository** → имя, например `pul-hisob` → **Public** → **Create repository**.
3. На странице репозитория: **uploading an existing file** → перетащи 6 файлов
   (`index.html`, `manifest.webmanifest`, `sw.js`, три `icon-*.png`) → **Commit changes**.
4. **Settings** → **Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/(root)** → **Save**.
5. Через 1–2 минуты появится адрес вида `https://ТВОЙ-ЛОГИН.github.io/pul-hisob/`.
6. На iPhone открой этот адрес **в Safari** → кнопка «Поделиться» (квадрат со стрелкой) →
   **«На экран Домой»** → **Добавить**.
7. Дальше открывай только **с иконки**, не из Safari: у иконки своё хранилище данных.

> Код в публичном репозитории виден всем, но **твои записи туда не попадают** — они хранятся только в телефоне.

## Проверка после установки (2 минуты)

1. Открой с иконки, добавь 2–3 тестовые записи.
2. Включи «Авиарежим», закрой приложение и открой снова — должно открыться, записи на месте.
3. «Настройки → Safari → Очистить историю и данные» → открой с иконки — записи должны остаться.
4. Удали тестовые записи (нажать на запись → «O'chirish»).

## Резервная копия

Sozlamalar → **Nusxani faylga saqlash** → «Сохранить в Файлы» (лучше в iCloud Drive).
Восстановление: Sozlamalar → **Nusxadan tiklash** → выбрать файл.
Если копии нет 7 дней — на главном экране появится жёлтое напоминание.

**Данные пропадут**, если удалить иконку с экрана «Домой» без копии.

## Обновление приложения

Загрузи новый `index.html` в тот же репозиторий (Add file → Upload files). Телефон подхватит
новую версию при следующем открытии с интернетом. Записи при обновлении не трогаются.

## Проверка на компьютере

```bash
node pul-hisob/serve.js
```

Потом открыть http://localhost:8765
